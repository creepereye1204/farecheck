# product.md — 왜, 누구를 위해, 어디까지

## 1. 문제: 신고는 들어오는데, 검증이 안 돼서 묻힌다

- 서울시에 접수된 외국인 관광객 택시 부당요금 신고는 2021년~2026년 8월 **6,481건**. 이 중 행정처분까지 간 건 **204건(3.1%)**.
- 별도 처분 없이 자체 종결된 사례가 **4,368건(67.4%)**. 종결 사유 1위는 '기타'로, 서울시는 이를 사실조사 과정에서 위반행위를 확인하기 어려운 사건이라고 설명했다.
- '기타' 종결 비율은 2023년 38.8% → 2025년 56.2% → 2026년 8월 60.7%로 계속 오르고 있다.
- 신고 창구는 이미 있다. 서울시는 2025년 6월 택시 QR 신고 시스템을 열었고 외국인 신고가 급증했다. 2025년 12월부터는 영수증에 영문 병기와 할증 여부 표시도 시작했다.
- 실제 피해 규모는 크다. 명동→김포공항 48만원(평소의 약 16배), 서울 동부→인천공항 약 69만원 같은 사례가 보도됐다.

**핵심 관찰:** 병목은 "신고 접수"가 아니라 "신고 검증"이다. 관광객이 낸 신고에는 경로, 정상 요금, 할증 적용 근거가 없어서 담당자가 사실을 확인하지 못한다.

## 2. 해결: 신고를 '검증 가능한 신고'로 만든다

관광객이 영수증과 승하차 정보를 올리면:
1. 영수증 필드를 추출하고 관광객이 확인한다.
2. 실제 도로 경로를 조회해 **정상 미터기 요금의 상한**을 계산한다.
3. 상한 대비 비율과 할증 규칙 위반 여부로 등급을 매긴다.
4. 계산 과정을 숫자 그대로 담은 **한국어 신고서**를 만든다. 담당 공무원은 검산만 하면 된다.

**연기체크(예비군 훈련연기 증빙 교차검증)와 같은 구조다:** 증빙 → 공공 기준과 교차검증 → 판정 근거 → 담당자 처리.

## 3. 사용자

| 사용자 | 원하는 것 | 이 서비스가 주는 것 |
|---|---|---|
| 외국인 관광객 | "내가 바가지 쓴 건가?" 확인, 신고 방법 | 자기 언어로 된 판정과 설명, 복사해서 낼 신고서 |
| 서울시·재단 담당자 | 처분 가능한 신고, 문제 구간 파악 | 검산 가능한 숫자가 담긴 신고서, (본선) 구간별 집계 |
| 성실한 택시 기사 | 억울한 신고 방지 | 넉넉한 상한 + "사기" 단정 금지 + 사용자 확인 단계 |

## 4. POC 범위 (서류 제출 전)

**포함**
- 모바일 웹 1페이지: 영수증 업로드 → 추출 확인 → 출발/도착 입력 → 결과
- 서울 중형택시, 미터기 결제 건
- 판정 3등급 + UNSUPPORTED
- 한국어 신고서(템플릿) + 영어 설명
- 평가셋 30건과 결과 리포트 (`docs/eval.md`)

**제외 (본선 24시간 또는 그 이후)**
- 재단용 대시보드 (구간·시간대별 의심 건수 지도) → **본선 핵심 확장**
- 다국어 확장(중·일), 앱 호출료 모델링
- 쇼핑·숙박 바가지
- 신고 자동 접수 (공개 API 없음. 신고서 복사 + 공식 신고 경로 안내까지만)
- 회원가입, 결제, 푸시

## 5. 시연 시나리오 (본선 무대용 초안)

1. "일본인 관광객이 명동에서 김포공항까지 택시를 탔고 48만원을 냈습니다." (보도 사례)
2. 휴대폰으로 영수증 사진 업로드 → 금액·시각이 자동으로 채워진다.
3. 출발지 '명동', 도착지 '김포공항' 선택.
4. 결과: **명백한 초과 — 이 경로의 정상 요금 상한은 약 3만원, 청구 금액은 약 16배.**
5. 한국어 신고서 화면: 경로 거리, 소요시간, 적용 요금표, 상한 계산식이 한 장에 정리돼 있다.
6. 마무리 멘트: "지금까지 이런 신고의 67%는 확인이 어려워 종결됐습니다. 이 신고서는 담당자가 3분 안에 검산할 수 있습니다."

## 6. 재단 관점 (개발계획서용)

- 택시 단속 권한은 서울시 택시정책과에 있다. 재단의 역할은 **관광객 접점 채널**(Visit Seoul, 관광안내소, 관광플라자)에서 이 도구를 배포하고, 쌓이는 집계로 "외국인이 바가지를 겪는 구간과 시간대"를 관광 정책 데이터로 쓰는 것이다.
- 운영 비용: 1건당 LLM 호출 2회(추출 1, 설명 1) + 카카오 API 2~3회. 판정 자체는 코드라 비용이 들지 않는다.
- 개인정보: 영수증 이미지와 차량번호는 서버에 저장하지 않는다 (`ARCHITECTURE.md`).
